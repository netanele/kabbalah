## צבעי הספירות
בכל דף, ציור, ייחוד או תרשים שיש בו ספירות או שמות קדושים משתמשים רק בצבעים האלה, מתוך שיר הספירות (`tzayach-shir-hasefirot.html`):

**המקום האחד:** הצבעים עצמם כתובים רק בקובץ `js/sefirot-methods.js`, יחד עם כל השיטות האחרות מטבלת ההשוואה. משם נבנית טבלת ההשוואה בדף שיטות בצבעי הספירות, ומשם נצבעים העץ והטבלה בדף שיר הספירות, הייחודים והעצים באוצר הייחודים, העצים בדף הבית ודוגמיות הצבע של שיטת הרמ"ק בדף המדיטציה (כל אלמנט עם `data-sef="<ספירה>"`). משנים צבע שם, והכול מתעדכן. הטבלה כאן היא העתק לעיון.

| ספירה | הצבע | צבע בקוד | השם שנאמר בה בשיר |
|---|---|---|---|
| כתר | לבן בוהק, בלתי נראה, כמו אוויר | `#ffffff`→`#eee8da`, קו מקווקו `#cbbd9c` | אהי"ה |
| חכמה | תכלת, גוון הכולל כל הגוונים | `#5b9bd5` עם טבעת קשת | י"ה |
| בינה | צהוב וירוק | `#f2c94c` / `#3faa5a` | אלקים חיים |
| חסד | לבן וכסף | `#ffffff` / `#b9bec7` | אל |
| גבורה | אדום וזהב | `#c62828` / `#d4a017` | אלקים |
| תפארת | צהוב וסגול | `#f2c94c` / `#7e3fa6` | הוי"ה |
| נצח | ורוד בהיר | `#f7b8cb` | ה' צבאות |
| הוד | ורוד כהה | `#b0305f` | אלקים צבאות |
| יסוד | כתום | `#f08a24` | אל חי |
| מלכות | כחול | `#1f4ea3` | אדנ"י |

- שם קדוש מקבל את צבע הספירה שבה הוא נאמר בשיר.
- אין סוף למעלה מכל הספירות: בלי צבע של ספירה, רק אור.
- בשם משולב כל אות שומרת על צבע השם שממנו באה.

## כללים לדף המדיטציה
- רק מספרי ישראל; לא משווים לדתות אחרות.
- ה"אני" בדף הוא נתנאל.
- את שם הוי"ה לא כותבים במלואו, גם לא בתמונות.

## הערות
- הגופנים נטענים מהאינטרנט; בלי חיבור הדפים יוצגו בגופן חלופי.
- קישורי הקריאה בדף המדיטציה פותחים את ספריא, ארכיון האינטרנט ואתרים אחרים, ודורשים חיבור לאינטרנט.
