# ספריית הקבלה

דפי לימוד ועיון. פותחים את `index.html` בדפדפן.

| קובץ | מה יש בו |
|---|---|
| `index.html` | דף הבית: שלושת הדפים, ו"בין שני הדפים" (שיטות בדף המדיטציה שבאות מתורת רבי אברהם אבולעפיה) |
| `abulafia.html` | כתבי רבי אברהם אבולעפיה |
| `meditation.html` | שיטות המדיטציה היהודית: מספרי הרב אריה קפלן ומספרי רבותינו |
| `sages-timeline.html` | ציר הזמן של חכמי ישראל, 1380–2012: 151 חכמים בשנים־עשר דורות, סינון לפי קבוצה, מי חי באותן שנים, ו־17 אירועים. דוח הבדיקה והמקורות: `docs/sages-timeline-review.md` |
| `js/read-aloud.js` | הקראה בקול בשני דפי התוכן: סמל רמקול ליד כל כרטיס וכל כותרת |
| `js/find.js` | חיפוש בדף בשני דפי התוכן: הדגשת כל התוצאות, הבא/הקודם, ורשימת תוצאות |
| `cov/` | כריכות הספרים של דף המדיטציה (`<key>.jpg` גדולה, `<key>-s.jpg` קטנה, ו־3 עטיפות `.svg`) |
| `docs/` | הערות העבודה: מצב הדף, רשימת הכריכות שאושרה, דוח הביקורת מ־1.10.2026 |

## עיצוב
כל הדפים בעיצוב של דף אבולעפיה: רקע קלף `#f4f0e6`, כרטיסים `#fffdf8`, כותרת כהה עם זהב `#c9a75a`, גופנים Frank Ruhl Libre (כותרות) ו־Heebo (טקסט) מ־Google Fonts. מצב בהיר בלבד.

## כללים לדף המדיטציה
- רק מספרי ישראל; לא משווים לדתות אחרות.
- ה"אני" בדף הוא נתנאל.
- את שם הוי"ה לא כותבים במלואו, גם לא בתמונות.

## הערות
- הגופנים נטענים מהאינטרנט; בלי חיבור הדפים יוצגו בגופן חלופי.
- קישורי הקריאה בדף המדיטציה פותחים את ספריא, ארכיון האינטרנט ואתרים אחרים, ודורשים חיבור לאינטרנט.
